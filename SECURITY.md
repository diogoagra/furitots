# Segurança

## Relatar uma falha

Se você encontrou uma falha de segurança no Furito TS, **não abra uma issue
pública**. Use o relato privado do GitHub: na página do repositório, aba
**Security → Report a vulnerability**.

Ajuda muito dizer:

- a versão do app e o sistema (macOS ou Windows);
- o que um atacante precisa ter (estar no mesmo servidor, operar o servidor,
  estar na mesma rede, um arquivo que a vítima importa…);
- os passos para reproduzir, ou um teste que falha.

Depois da correção, o relato é publicado com o crédito a quem o encontrou, se
a pessoa quiser.

## O que o app protege

O modelo de ameaças, as defesas e os limites conhecidos (inclusive os do
protocolo do TeamSpeak) estão em [docs/seguranca.md](docs/seguranca.md).

## Versões

O projeto está na versão 1.0: as correções entram na versão mais recente.
